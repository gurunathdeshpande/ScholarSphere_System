# ScholarSphere

ScholarSphere is a comprehensive research management platform that aggregates faculty profiles, publications, and research trends.

## Tech Stack

-   **Backend**: Flask, MySQL, SQLAlchemy, JWT, Marshmallow
-   **Frontend**: React.js, Bootstrap
-   **ML**: Hugging Face Transformers (Zero-shot classification)
